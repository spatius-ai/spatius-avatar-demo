# Moved

The Spatius demos now live at **[spatius-integration-demo](https://github.com/spatius-ai/spatius-integration-demo)**.

```bash
git clone https://github.com/spatius-ai/spatius-integration-demo.git
```

Everything that was here is there, unchanged: Direct, Backend and RTC Mode, each with
its servers and its web, iOS, Android and Flutter clients, plus the LiveKit platform
integrations.

This repository keeps its directory tree so that links pointing into it — including
ones that go straight to a particular client, such as
`direct-mode/clients/web/reference/react` — still land somewhere that says where to
look instead. Nothing here is maintained.
